# VadimToptunov/homebrew-tap

Homebrew formulas for my tools.

```sh
brew install vadimtoptunov/tap/kassios
```

| Formula | What it is |
|---|---|
| `kassios` | Host-side tools for [KassiOS](https://github.com/VadimToptunov/KassiOS): `kassios agent`, `kassios mutants`, `kassios lint` |

The `kassios` formula is updated by KassiOS's release workflow when a release is published.
